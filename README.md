# Embiveni Meats Network — Cisco Packet Tracer Simulation

An enterprise network topology and simulation designed in **Cisco Packet Tracer** for **Embiveni Meats**, demonstrating structured network segmentation, routing, and end-to-end connectivity.

## 🛠️ Environment & Tools
* **Simulation Software:** Cisco Packet Tracer
* **Domain:** Enterprise Networking & Internet Technologies

## 🌐 Key Architecture & Features
* **Network Segmentation:** Structured departmental subnets and switch/router infrastructure for enterprise operations.
* **IP Addressing & Routing:** Configured IPv4 addressing schemes and inter-network routing to enable seamless communication across branches/departments.
* **Connectivity & Verification:** Tested and verified end-to-end packet delivery and device reachability across the topology.

## 🚀 How to View & Run
1. Download and install **Cisco Packet Tracer**.
2. Download `EMBIVENI MEATS NETWORK.pkt` from this repository.
3. Open the file in Cisco Packet Tracer and use **Realtime** or **Simulation** mode to inspect the topology, device configurations, and packet flow.
